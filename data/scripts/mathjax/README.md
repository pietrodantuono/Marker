# Bundled MathJax fallback

Unmodified MathJax 3.2.2 `es5/tex-svg-full.js`, from:
https://github.com/mathjax/MathJax/tree/3.2.2

Downloaded from https://raw.githubusercontent.com/mathjax/MathJax/3.2.2/es5/tex-svg-full.js
SHA-256: `a4354ff94fd868aea0cc6eaaa79a57fda0588646fc46ee3700a349ee0a11cbe6`

Apache License 2.0; the upstream license is retained in LICENSE. This combined
TeX/SVG component includes its font paths and TeX extensions. Marker disables its
context menu to avoid loading optional menu assets. No CDN is needed for this
fallback. Existing system MathJax 2 remains preferred when installed; KaTeX and
renderer preferences are unchanged. See https://docs.mathjax.org/en/v3.2/web/start.html.
