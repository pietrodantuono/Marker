# Notebook symbols

The icon-*-symbolic.svg notebook symbols are from toolstack/Folio, commit
 e0856acbd6b8776ca38c8802f7b932da6a40bd5b, under GPL-3.0-or-later.
https://github.com/toolstack/Folio/tree/e0856acbd6b8776ca38c8802f7b932da6a40bd5b/src/graphics/scalable/actions

Book geometry follows Folio's notebook_preview widget/style. Marker uses its own
C widget, shared appearance model, and contrast calculation.
